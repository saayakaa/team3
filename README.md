- [index.html](index.html)
- [styles.css](styles.css)
- [app.js](app.js)

主な機能:
- ①ログイン・新規登録
- ②推しの写真を設定する

- ⑤ユーザごとの課題管理

使用技術:
- HTML
- CSS
- JavaScript
- Firebase

- ①新規登録orログイン
