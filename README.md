# 推しTask　
### ～推し育成TODOリスト～
======
大学生の課題管理を推しの力で続けやすくするアプリ

ファイル:
- [index.html](index.html)
- [styles.css](styles.css)
- [app.js](app.js)    


 🚀 実行方法（アプリの動かし方）
1. このリポジトリをクローンするか、ZIPでダウンロードして解凍します。
2. team3 のフォルダを VS Code（Visual Studio Code）で開きます。
3. 推奨： VS Codeの拡張機能 「Live Server」 をインストールし、画面右下の「Go Live」ボタンを押して起動してください。
（※ index.html を直接ダブルクリックしてブラウザで開くことも可能ですが、Firebaseの機能が正しく動作しない場合があります）  

- 📝アプリの使い方:  
1. 新規登録orログイン  
2. 推しの写真を設定する  
3. 課題を設定する  
4. 課題が完了するとレベルが上がる(ファンとしてのレベルが上がる)  

主な機能:  
- ログイン・新規登録
- 推しの写真を設定する  
- 課題を設定する  
- 課題を達成すると推しのレベルがレベルアップ  
- ユーザごとの課題管理  

使用技術:
- HTML
- CSS
- JavaScript
- Firebase

開発メンバー:
- SAYAKA(ログイン担当)
- しの(ホーム画面)
- ひさめい(課題入力画面)
