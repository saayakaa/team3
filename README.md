# 推しTask

このアプリは、推しのタスクを管理するためのツールです。

## 実装済みの機能
- [x] Firebase Authenticationを用いたログイン機能
- [x] 新規会員登録機能（パスワード確認機能付き）

## 開発環境のセットアップ
1. このリポジトリをクローンする
2. `index.html` にFirebaseのConfig設定が含まれていることを確認する
3. `npm install` 等（必要であれば）を行う
4. ブラウザで `index.html` を開く
